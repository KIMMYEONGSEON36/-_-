# 구현 요구사항

## 핵심 기능 요구사항
- 유형별 요청 접수와 첨부, 제출 전 검토
- 요청 목록·상세와 상태 관리
- AI 분석 제안의 실행·수정·승인 및 승인 결과에서 작업 생성
- 작업 단계, 예상·실제 시간, 난이도, 우선순위, 마감일과 상태 관리
- 대시보드 요약과 빠른 접근

## 데이터 개요
Request, AI Analysis, Task, Task Step, Time Log를 중심으로 설계합니다. 요청과 작업의 연결을 유지하고 분석 버전을 보존합니다. 초기 개발은 가상 데이터와 로컬 또는 개발용 저장소를 사용합니다.

## 품질·오류 처리
- 입력 중 오류가 나도 가능한 범위에서 내용을 보존합니다.
- 저장·상태 변경의 성공과 실패를 표시합니다.
- AI 분석 실패 시 기본 업무 흐름을 중단하지 않고 수동 작업 생성 경로를 제공합니다.
- API 키, 개인정보, 내부 자료를 소스 코드에 하드코딩하지 않습니다.
- 실제 AI API 연결은 UI, 데이터 구조, 오류 처리를 검증한 다음 별도 단계로 진행합니다.

## 제안된 단계
1. 구조 설계 및 데이터 모델 정리
2. 가상 데이터 기반 UI 구현
3. 요청·작업·상태·시간 기록 기능
4. AI 결과 검토·승인·작업 생성
5. 사용성·오류·반응형 검증
6. 정책 검토 후 실제 저장소·AI·권한 확장
