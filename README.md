# Design Flow

디자인 요청 접수부터 업무 분해와 개인 작업 관리까지 지원하는 서비스의 가상 데이터 기반 프로토타입입니다.

## 실행

정적 웹 프로젝트이므로 `index.html`을 브라우저에서 열거나 정적 파일 서버에서 제공하면 됩니다. 별도 패키지 설치가 필요하지 않습니다.

## 배포 방향

GitHub 저장소에 이 프로젝트를 올린 뒤 Vercel에서 해당 저장소를 가져오면 정적 사이트로 배포할 수 있도록 구성했습니다.

## 현재 범위와 제한

- 요청 접수, 대시보드, 요청 상세, 작업 목록·상세, 일정 화면의 프로토타입
- 예시 업무는 가상 데이터입니다.
- 새 요청 및 변경 사항은 현재 브라우저의 `localStorage`에 저장됩니다. 브라우저 또는 기기가 달라지면 공유되지 않습니다.
- 로그인, 서버 데이터베이스, 실제 파일 업로드, 실제 AI 분석은 연결되어 있지 않습니다.
- 실제 개인정보나 회사 자료를 입력하지 마세요.

## 주요 파일

- `index.html`: 앱 진입점
- `styles.css`: 반응형 디자인과 화면 스타일
- `app.js`: 화면과 프로토타입 동작
- `vercel.json`: Vercel 정적 배포 설정
