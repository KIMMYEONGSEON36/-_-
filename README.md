# Design Flow

디자인 요청 접수와 디자이너 작업 관리, 공용 단가표 기반 견적 확인을 지원하는 웹 앱입니다.

## 실행

현재 화면은 정적 파일로 제공하며, 공유 데이터와 직원 로그인은 Supabase를 사용합니다. Supabase 스키마 설정 전에는 로그인과 저장 기능을 사용할 수 없습니다.

## 배포 방향

GitHub 저장소에 이 프로젝트를 올린 뒤 Vercel에서 해당 저장소를 가져오면 정적 사이트로 배포할 수 있도록 구성했습니다.

## 현재 범위와 제한

- 요청 접수, 대시보드, 요청 상세, 작업 목록·상세, 일정 화면의 프로토타입
- 요청 접수는 공개 제출과 로그인한 SV 제출을 지원합니다. SV는 요청 상태와 작업 진행을 조회할 수 있고 수정은 할 수 없습니다.
- 요청·작업·단가 데이터는 Supabase 프로젝트에 공유 저장됩니다.
- 간편 견적은 관리자가 설정한 품목별 최소 수량과 주문 단위에 맞춰 계산하며, 품목·규격·재질·인쇄면을 바꾸면 해당 조건의 수량으로 갱신됩니다. 인쇄 단가에는 부가세와 기본 배송비가 포함되고, 제주 추가 배송비와 선택한 디자인비가 반영됩니다.
- 디자인비 기준은 단순 수정형(하: 텍스트 5,000원, 규격 변경 10,000원, 사진 보정·합성 20,000원, 디자인 요소 추가·수정 30,000원)입니다. 일반 제작(중)과 신규 제작(상)은 접수 후 별도 견적합니다. 간편 견적은 점주의 단순 문의를 위한 참고 금액으로, 실제 금액은 작업·제작 조건에 따라 달라질 수 있으며 주문 접수 후 상세 견적을 안내합니다.
- 요청 첨부와 시안 검토 링크는 비공개 Supabase Storage와 Vercel API 환경 설정 후 사용할 수 있습니다. AI 분석은 연결되어 있지 않습니다.
- 기존 Supabase 프로젝트는 `supabase/migrations/20261119_request_catalog_duplex_and_reviews.sql`을 적용해야 품목별 주문 단위, 양면 단가, 수정 요청 첨부 기능을 사용할 수 있습니다. 요청자 연락처는 접수 항목에서 수집하지 않습니다.

Supabase 연결 방법과 역할 설정은 [`supabase/SETUP_KO.md`](supabase/SETUP_KO.md)를 확인하세요.

## 주요 파일

- `index.html`: 앱 진입점
- `styles.css`: 반응형 디자인과 화면 스타일
- `app.js`: 화면과 프로토타입 동작
- `vercel.json`: Vercel 정적 배포 설정
- `supabase/schema.sql`: 데이터베이스 테이블과 권한 정책
- `supabase-config.js`: 브라우저용 공개 프로젝트 설정
