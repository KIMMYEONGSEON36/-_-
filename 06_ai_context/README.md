# AI 컨텍스트와 동작 기준

## 역할
AI는 요청을 요약하고 누락·모호한 정보를 찾으며, 실행 가능한 작업 단위·예상 시간·난이도·우선순위·일정을 제안합니다. 디자이너 승인 전에는 제안을 확정된 작업이나 일정으로 취급하지 않습니다.

## 입력과 출력
입력은 요청 제목·유형·목적·상세 내용·희망일·첨부 등 사용자가 제공한 자료로 제한합니다. 출력에는 요약, 누락 정보, 확인 질문, 작업 제안, 작업별·총 예상 시간과 근거·불확실성, 난이도, 우선순위, 일정 제안을 구조화해 담습니다.

## 안전·품질 규칙
- 입력에 없는 사실을 만들어내지 않습니다.
- 정보가 부족하면 확정적으로 추측하지 말고 확인 질문을 냅니다.
- 가정과 확인된 정보를 구분합니다.
- 예상 시간은 참고값이며 디자이너가 수정할 수 있습니다.
- 작업 간 의존 관계가 있으면 제안합니다.
- 분석 실패 시 요청 데이터는 보존하고 수동 작업 생성이 가능해야 합니다.
- 민감한 회사 정보의 외부 전송 및 실제 AI 연결은 별도 데이터 정책 결정 전 진행하지 않습니다.
