# 프로젝트 개요

## 서비스 소개
디자인 요청 접수부터 내용 정리, 작업 분해, 예상 시간 산정, 일정과 우선순위 관리까지 개인 디자이너의 업무 흐름을 지원하는 웹 서비스(가칭: 디자인 플로우)입니다.

## 목표
- 요청자가 전문 용어 없이 디자인 요청을 제출할 수 있게 합니다.
- 디자이너가 요청, 작업, 일정, 실제 소요 시간을 한곳에서 관리할 수 있게 합니다.
- AI는 요약과 업무 계획을 제안하고, 최종 결정은 디자이너가 합니다.

## MVP 범위
요청 접수, 요청 상세 확인, AI 분석 제안의 검토·수정·승인, 작업 목록 및 상태 관리, 대시보드와 시간 기록을 가상 데이터로 우선 검증합니다.

## 원칙과 제외 범위
개인 사용 중심으로 시작하며 기존 사내 플랫폼을 대체하거나 실제 회사 데이터를 외부 AI로 자동 전송하지 않습니다. 팀 자원 관리, 결재, 실시간 사내 연동은 MVP 범위에서 제외합니다.

## 기준 자료
상세 기준은 프로젝트 루트의 `디자인플로우.pdf`와 `Design_Flow_Project_Knowledge_Pack`을 참고합니다. 결정되지 않은 사항은 임의로 확정하지 않고 별도 기록합니다.
