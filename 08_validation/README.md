# 검증 기준

## 핵심 시나리오
1. 모바일에서 요청 유형을 선택하고 입력·첨부 후 제출합니다.
2. 디자이너가 신규 요청 상세와 첨부를 확인합니다.
3. AI 제안의 요약·누락 정보·작업·시간을 수정하고 승인합니다.
4. 승인된 분석에서 여러 작업을 생성하고 상태와 마감일을 조정합니다.
5. 실제 소요 시간을 기록하고 대시보드에서 오늘 할 일과 지연 업무를 확인합니다.
6. AI 분석 실패 상황에서도 요청이 보존되고 수동으로 작업을 만들 수 있습니다.

## 확인 항목
- 필수 입력 검증, `미정` 입력 처리, 제출 후 확인 피드백
- 요청과 작업 간 연결 및 상태 전이
- 분석 결과 편집·저장·승인과 버전 확인
- 예상 시간·실제 시간 기록과 합계 표시
- 로딩, 빈 상태, 오류, 저장 중·완료 상태
- 모바일·데스크톱 반응형 및 표의 모바일 대응
- 상태를 텍스트·아이콘과 함께 전달하는지

사용자 테스트 결과와 검증 리포트를 기록하고, 발견된 문제를 우선순위별 반복 작업 목록에 연결합니다.
