# 디자인 기준

## 서비스 인상
명확하고 가벼우며 전문적인 업무 도구를 지향합니다. 장식보다 정보 위계와 여백을 통해 상태, 일정, 작업량, 다음 행동을 전달합니다.

## 화면별 방향
- 요청자: 모바일 우선, 단계형 폼, 진행 표시, 선택형 질문, 첨부와 제출 전 검토.
- 디자이너: 데스크톱 우선, 사이드 내비게이션과 메인 콘텐츠, 요약 카드, 필터 가능한 목록, 상세·일정·작업 보기.
- AI 검토: 원본 요청과 제안 내용을 비교하고 각 제안을 편집·승인할 수 있게 합니다.

## 반응형 및 상태
모든 주요 화면은 데스크톱·모바일에서 사용할 수 있어야 합니다. 모바일 표는 카드형 또는 가로 스크롤로 대응합니다. 초기 로딩, 빈 상태, 오류, 분석 중·실패, 저장 중·완료 상태를 설계합니다.

## 접근성·표현 체크
상태는 텍스트와 아이콘을 함께 사용합니다. 버튼 비활성 조건과 오류 메시지를 분명히 표시하고, 모바일 입력 화면에 한꺼번에 과도한 질문을 넣지 않습니다.

## 산출물
와이어프레임, UI 컨셉, 디자인 시스템, Figma 참고 자료를 이 폴더에 정리합니다.
