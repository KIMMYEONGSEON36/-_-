# 정보 구조 및 사용자 흐름

## 요청자 흐름
서비스 접속 → 요청 유형 선택 → 유형별 질문 입력 → 참고 자료 첨부 → 입력 검토 → 제출 완료 → 상태 확인

## 디자이너 흐름
대시보드 → 신규 요청 확인 → 요청 상세 검토 → AI 분석 실행 및 결과 수정 → 승인 → 작업 생성 → 일정·우선순위 조정 → 진행·완료 처리 → 실제 시간 기록

## 주요 화면
요청 시작, 유형 선택, 요청 입력, 요청 검토, 제출 완료, 디자이너 대시보드, 요청 목록·상세, 작업 목록·상세, 일정, 설정·기준.

## 핵심 데이터 관계
- Request는 여러 버전의 AI Analysis를 가질 수 있습니다.
- 승인된 분석에서 여러 Task를 생성합니다.
- Task에는 여러 Task Step과 Time Log가 연결됩니다.

## 상태
요청: 접수, 검토 중, 정보 요청, 분석 완료, 작업 진행, 완료, 보류, 취소.

작업: 대기 → 진행 중 → 검토 → 완료. 필요하면 보류 상태로 전환합니다.
