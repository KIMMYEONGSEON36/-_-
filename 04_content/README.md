# UX 콘텐츠 및 문구

## 콘텐츠 원칙
- 전문 용어 대신 쉬운 표현과 선택지를 사용합니다.
- 요청 유형에 맞는 질문만 보여주고, 입력 예시를 제공합니다.
- 사용자가 모르는 값은 가능한 경우 `미정`으로 제출할 수 있게 합니다.
- 진행 상태와 다음 행동을 명확히 안내합니다.
- 오류·빈 상태·저장 중·저장 완료를 색상만으로 표현하지 않습니다.

## 요청 유형별 질문 영역
| 유형 | 주요 입력 |
| --- | --- |
| 신규 제작 | 사용 위치·목적, 전달 내용, 매체, 참고 이미지, 필수 문구, 희망 일정 |
| 일반 제작 | 기존 시안 또는 제작물, 변경·구성 내용, 참고 자료, 희망 일정 |
| 재주문 | 기존 제작물, 수량, 변경 여부, 배송·출력 정보 |

## 상태·피드백 문구 체크리스트
- 필수 입력이 빠졌을 때 해당 항목과 해결 방법을 안내합니다.
- AI 분석 실패 시 입력 내용을 보존하고 수동 작업 생성 경로를 안내합니다.
- 저장 성공·실패와 상태 변경 결과를 사용자에게 알려줍니다.
- 확인이 필요한 정보와 AI의 가정 사항을 구분해 표시합니다.
